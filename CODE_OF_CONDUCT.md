# Code of Conduct

## Our standard

This project welcomes people of every background and experience level. Be
direct about technical problems, generous about intent, and specific about
evidence.

Examples of behavior that help the project:

- explaining a failure with a reproduction and diagnostics;
- disagreeing with an idea without attacking the person;
- correcting a claim when new evidence appears;
- giving newcomers room to ask questions; and
- respecting privacy and not publishing another person's data.

Harassment, discrimination, threats, sexualized attention, deliberate
misinformation, and publishing private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, code
review, and other spaces where someone is representing the project.

## Enforcement

Report abusive behavior privately to the repository owner through their GitHub
profile. Reports will be reviewed in good faith and kept confidential as far
as practical.

Maintainers may edit or remove content, close a thread, issue a warning, or
temporarily or permanently ban participation, depending on severity and
pattern. Retaliation against a reporter is itself a violation.
