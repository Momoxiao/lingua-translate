Lingua 0.2.2 fixes a realtime-caption fallback bug where YouTube's caption
language/settings prompt could be mistaken for dialogue.

**Fixed**
- The realtime fallback now ignores YouTube's "language / click / view settings"
  UI instead of translating it as a subtitle line.
- Zero-width direction marks and control characters no longer count as a caption.
- The live YouTube smoke test now records the caption DOM that produced the
  fallback, so this class of bug is visible when it happens again.

**Install**
1. Download `lingua-0.2.2.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.2.zip.sha256
```
