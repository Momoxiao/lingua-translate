Lingua 0.2.3 keeps the extension's toolbar tooltip in sync with the UI language
and finishes the mobile homepage fixes from the 0.2.2 release.

**Fixed**
- The toolbar tooltip now follows the selected UI language instead of always
  using the manifest's Chinese fallback.
- The project homepage keeps its GitHub link, language switcher, and caption
  demo usable on narrow phones without horizontal overflow.

**Install**
1. Download `lingua-0.2.3.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.3.zip.sha256
```
