Lingua 0.2.4 reduces the delay of the realtime caption fallback used on YouTube
live streams and when the whole caption track cannot be fetched.

**Improved**
- Live captions are polled every 100 ms instead of 220 ms, with no long wait for
  a line to stop changing before translation starts.
- OpenAI-compatible providers stream single-line translations as they are
  generated instead of waiting for the response to finish.
- A newer caption cancels the previous in-flight translation, so stale partial
  or final text cannot overwrite the line currently on screen.
- Failed live requests retry safely without hammering the provider.

**Install**
1. Download `lingua-0.2.4.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.4.zip.sha256
```
