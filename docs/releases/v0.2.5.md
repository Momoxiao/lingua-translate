Lingua 0.2.5 makes the YouTube caption path recover instead of settling for
realtime mode.

**Fixed**
- If the player's PoToken arrives after the first caption-fetch window, Lingua
  now keeps translating lines in realtime and retries the complete track in the
  background instead of leaving the page permanently degraded.
- Once a retry retrieves the full track, the cues are published and realtime
  polling stops automatically, restoring pre-translated captions without a page
  reload.
- The reusable signed caption template is stored with its video id again, so
  subsequent retries can reuse the player's PoToken instead of skipping that
  path.
- The fallback status now says what is actually happening: realtime output is a
  temporary bridge while Lingua retries the complete track.

**Install**
1. Download `lingua-0.2.5.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.5.zip.sha256
```
