Lingua 0.2.6 fixes two ways a video with captions could stay in realtime
fallback even though its full caption track was available.

**Fixed**
- A response that contains only YouTube's `pb3` style tables and no caption
  events is no longer treated as a successful track. Lingua asks again with
  the signed URL instead of parsing the style-only response as zero cues.
- Background upgrade retries now pause while a pre-roll ad is playing and
  resume after it ends, instead of spending the retry budget on an ad player
  response that cannot contain the video's caption track.
- The background upgrade window now keeps retrying for longer, covering the
  common case where YouTube mints its PoToken after the first request.
- Diagnostics still distinguish an empty response from a non-empty response
  that cannot be parsed, so the remaining failure modes stay reportable.

**Install**
1. Download `lingua-0.2.6.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.6.zip.sha256
```
