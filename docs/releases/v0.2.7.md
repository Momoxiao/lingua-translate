Lingua 0.2.7 adds a full-caption fallback that does not depend on YouTube's
page-minted Proof-of-Origin token.

**Fixed**
- When the page-signed caption chain fails, the background worker now asks
  YouTube's mobile player endpoint for the same video and fetches that
  response's caption track. The request is made only after the existing
  strategies fail, so the normal fast path is unchanged.
- The mobile path tries the iOS client first and Android second, matching the
  selected caption language and forcing `json3` for reliable parsing.
- Realtime caption scraping is now the final rescue rather than the first
  response to a signed-URL timing miss.

**Measured**
- Direct check on `dQw4w9WgXcQ`: the iOS response listed 6 caption tracks; the
  `en` track returned 8,079 bytes and 61 cues with no `pot` in the URL.

**Install**
1. Download `lingua-0.2.7.zip`.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the unzipped folder.
4. Pick a provider in Settings and paste your own API key.

No account and no server operated by the project. Your API key stays in your
browser.

**Verify the download**
```bash
shasum -a 256 -c lingua-0.2.7.zip.sha256
```
