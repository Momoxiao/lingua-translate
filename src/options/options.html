使用说明

为什么需要扩展在页面内取字幕

2025 年起 YouTube 给字幕接口加上了 PoToken 校验，任何脱离页面的直接请求都会返回空。本扩展运行在 YouTube 页面内，先尝试用页面上下文复用播放器已经拿到的凭证去取整条字幕轨；若失败，则自动打开原生字幕并截获播放器自身发出的请求，因此始终能拿到字幕。

自定义 API 模板

选择「自定义 API 模板」后，可以用占位符拼装任意 HTTP 接口：

  • {{text}} 整批字幕文本（编号后的多行字符串）
  • {{texts}} 原始句子数组（JSON 字面量）
  • {{from}} / {{to}} 语言代码
  • {{source}} / {{target}} 语言名称
  • {{key}} API Key

请求体返回编号文本即可自动对齐；若接口返回数组，可用「响应取值路径」指定，例如 data.translations 或 result[0].text。

性能建议

  • 整片预取：进入视频后一次性获取全部字幕，边播边翻，不依赖播放进度。
  • 优先级调度：先翻播放位置附近，再向前推进，拖动进度条会自动重新排优先级。
  • 缓存：同一句只翻一次，重看或换视频都能命中。
