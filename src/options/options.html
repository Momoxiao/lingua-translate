使用说明

怎么用

  • 网页翻译：页面上有个悬浮球，点一下就开始翻译；也可以点工具栏图标。
  • 视频字幕：打开 YouTube 视频会自动翻译字幕，双语叠加在画面上。
  • 快捷键：点扩展图标 → 弹窗里可切换显示方式与本站规则。

为什么字幕要在页面内获取

2025 年起 YouTube 给字幕接口加上了 PoToken 校验，任何脱离页面的直接请求都会返回空。本扩展运行在 YouTube 页面内，复用播放器自己铸造的凭证去取整条字幕轨，因此始终能拿到字幕。

自定义 API 模板

选择「自定义 API 模板」后，可以用占位符拼装任意 HTTP 接口：

  • {{text}} 整批文本（编号后的多行字符串）
  • {{texts}} 原始句子数组（JSON 字面量）
  • {{from}} / {{to}} 语言代码
  • {{source}} / {{target}} 语言名称
  • {{key}} API Key

请求体返回编号文本即可自动对齐；若接口返回数组，可用「响应取值路径」指定，例如 data.translations 或 result[0].text。

速度建议

  • 翻译建议用非推理模型：推理模型的「思考」对翻译是纯浪费，实测慢一倍。
  • 批越大请求越少，但失败时影响面也更大；并发太高可能触发接口限流。
  • 缓存跨视频、跨网站生效，同一句话只翻一次。
